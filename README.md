## 📌 О проекте

**Autoschool** — учебный проект, посвящённый разработке веб-сайта автошколы.

Основная цель проекта — практика навыков веб-разработки, создание удобного пользовательского интерфейса и изучение принципов построения современных веб-страниц.

> ⚠️ Проект создан исключительно в образовательных целях и не является официальным сайтом реальной автошколы.

## 🛠️ Технологии

- **HTML5** — структура веб-страниц.
- **CSS3** — стилизация и оформление интерфейса.
- **JavaScript** — интерактивность и логика сайта *(по мере реализации)*.

## 🚀 Запуск проекта

1. Склонируйте репозиторий:

   ```bash
   git clone <URL-ВАШЕГО-РЕПОЗИТОРИЯ>
   ```

2. Перейдите в папку проекта.
3. Откройте `index.html` в браузере или запустите проект через расширение **Live Server** в Visual Studio Code.
